# kicknclick

kicknclick is a full-stack web application that demonstrates the interaction
between a Java-based backend and a modern TypeScript frontend.
The project follows a clear separation of concerns and an API-driven design.

## Tech Stack
- **Backend:** Java
- **Frontend:** TypeScript, HTML, CSS
- **Architecture:** Client–Server, REST-based communication
- **Tools:** Git, Node.js, npm

## Project Structure
kicknclick/
├── BE/     # Backend service (business logic and APIs)
└── FE/     # Frontend application (user interface)

## Features
- Frontend and backend developed as separate modules
- API-driven communication between FE and BE
- Modular and maintainable project structure
- Suitable foundation for scalable web applications

## Getting Started

### Backend Setup
cd BE
mvn clean install
mvn spring-boot:run

Backend URL:
http://localhost:8080

### Frontend Setup
cd FE
npm install
npm run dev

Frontend URL:
http://localhost:5173

## Purpose
This project showcases full-stack development skills with a strong focus on
backend–frontend integration using Java and TypeScript.
